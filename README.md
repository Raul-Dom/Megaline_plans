# Megaline — Plan Revenue Analysis (EDA + Statistical Testing)

This repository contains a portfolio-ready version of a data analysis project that compares two prepaid telecom plans (**Surf** vs **Ultimate**) using customer behavior data.

## Objective
- Build a monthly user-level dataset from multiple related tables (users, calls, messages, internet usage, and plan details)
- Compute monthly revenue per user based on plan rules (fixed monthly fee + overage charges)
- Compare plan performance using descriptive statistics and hypothesis testing

## What you'll find
- `Proyecto_S5_Portfolio.ipynb` — Clean, narrative-focused notebook (outputs included)

## Tech stack
Python, pandas, NumPy, SciPy, Matplotlib, Seaborn

## Notes on reproducibility
The original dataset path in the notebook uses `/datasets/...` (as provided by the course environment).  
If you want to run it locally, update the file paths to your local dataset location.
